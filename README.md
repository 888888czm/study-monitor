📚 智能学习监控系统 (Smart Study Monitor)
这是一个基于 Python、PyQt5 和 OpenCV 开发的桌面端学习辅助与专注度监控系统。旨在通过技术手段辅助学生进行日常的预习、学习与复习规划，并通过摄像头检测专注度，最终生成可供教师审核的学习报告。

✨ 核心功能
📖 书籍录入与规划：通过输入书籍序列号自动匹配书名，并可设定当日的学习任务类型（预习/学习/复习）、规定时间及规定页数。
👁️ AI 专注度监测：利用 OpenCV 调用本地摄像头，实时检测画面中的人脸状态。
🚨 分神录像与报警：若在规定时间内离开座位或长时间未检测到人脸，系统会自动报警，并在本地录制 3 秒的“分神证据”视频片段。
⏱️ 灵活控制：支持随时开始、暂停和停止学习任务，剩余时间实时显示。
📝 教师审核机制：系统无法自动判断真实阅读页数，因此学习结束后，教师可在“历史数据”中手动录入学生实际完成的页数，并评定是否达标。
📊 报告生成与导出：支持查看历史记录，并可一键导出包含“规定页数、实际页数、差额、专注度”等数据的 PDF 学习报告。
快速开始：
方案一（生成.exe文件）
🛠️ 环境依赖
Python 3.8 及以上
PyQt5
OpenCV (opencv-python)
ReportLab (用于生成 PDF)
安装依赖：

pip install PyQt5 opencv-python reportlab

🚀 运行与打包
直接运行源码：

bash
python study_monitor.py
打包为独立 EXE 文件（Windows）：

bash
python -m PyInstaller -y --onedir --console --clean --collect-all cv2 --collect-all PyQt5 --collect-all reportlab study_monitor.py
📁 目录结构说明
study_monitor.py：主程序代码。

study_data.json：自动生成的本地数据库文件，用于存储历史学习记录。

distractions/：自动生成的文件夹，用于存放监控过程中抓拍的“分神录像”。

error_log.txt：程序发生异常崩溃时自动生成的日志文件，用于排查问题。
